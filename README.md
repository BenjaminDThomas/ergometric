Developed a fully functional e-commerce website for Ergometric using Shopify, where I managed the design, mobile/desktop accessibility, and SEO optimisation. I created and implemented all product listings, ensuring that the site was both user-friendly and optimised for search engines.

Using Figma, I designed the website’s wireframes and prototypes, collaborating closely with the Ergometric team to align the design with business goals and user needs. Regular communication with the team allowed for continuous feedback and refinement, ensuring a seamless navigation system and a consistent user experience across all devices.

I also integrated Elfsight widgets to enhance business features, such as displaying opening hours, and worked to ensure a smooth and intuitive user journey throughout the site.
